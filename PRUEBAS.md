# Plan de pruebas — NoVa

Este documento recoge las pruebas realizadas sobre la API de NoVa durante la Fase 1 del proyecto.

## Entorno de pruebas

- Backend: Python + Flask
- Puerto: 8080
- Formato de intercambio: JSON
- Herramienta utilizada para las pruebas manuales: PowerShell `Invoke-RestMethod`

## Pruebas realizadas

Las pruebas se documentarán indicando:

- Identificador de la prueba.
- Objetivo.
- Petición realizada.
- Resultado esperado.
- Resultado obtenido.
- Estado de la prueba.
